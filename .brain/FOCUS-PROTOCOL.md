## The Loop (name it to break it)

```
Phone within reach → "just 1 min" scroll → feed / YT autoplay → 2-3h gone
        → mood drop → compulsive habit → guilt ─┐
                                                ▼
     "today is already wasted" → 0 study → confidence ↓ → repeat tomorrow
```

**Only the first step is hard to stop. So never start it.** Breaks are walk / water / food. **Screens are not a break — they are the trap door.** Screen-breaks are where every lost day begins.

## The 15-Minute Urge Rule (phone or habit)

1. **Name it out loud:** "This is an urge. It peaks in ~10–15 min."
2. **Stand up + drink water** (2 min).
3. **Set a 15-min timer**, do **5 practice questions** (micro-task).
4. Urge usually collapses. If not, repeat once.

**Defer, don't fight — "later, not now."** The brain accepts delay far better than denial. You are not quitting anything this week; you are just making it logistically hard until 23 Sept.
