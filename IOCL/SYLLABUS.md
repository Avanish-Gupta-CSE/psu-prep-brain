## 📘 Section A: Technical Domain Knowledge (CS & IT)

### 1. Data Structures & Algorithms
- Arrays, Stacks, Queues, Linked Lists, Trees (Binary Trees, BST, AVL Trees, Heaps).
- Graphs (BFS, DFS, Dijkstra, Kruskal, Prim, Topological Sort).
- Searching, Sorting (Merge, Quick, Heap, Counting), Time & Space Complexity analysis.
- Dynamic Programming, Greedy Approach, Divide and Conquer.

### 2. Operating Systems
- Process Management, CPU Scheduling algorithms, Threads and Concurrency.
- Process Synchronization, Semaphores, Mutex, Monitors, Deadlocks (Detection, Prevention, Avoidance, Recovery).
- Memory Management: Paging, Segmentation, Virtual Memory, Page Replacement algorithms (FIFO, LRU, Optimal).
- File Systems, Disk Scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN).
- Linux / Unix basic shell commands, file permissions, and system calls.

### 3. Database Management Systems (DBMS)
- Relational Model, ER-Diagrams, Relational Algebra, SQL queries (JOINs, Nested Queries, Aggregations, Group By, Having).
- Normalization (1NF, 2NF, 3NF, BCNF) and Functional Dependencies.
- Transactions, ACID properties, Concurrency Control (2PL, Timestamp ordering), Recovery techniques.
- Indexing, B-Trees, B+ Trees, NoSQL concepts basics.

### 4. Computer Networks
- OSI Reference Model & TCP/IP Protocol Stack.
- Physical & Data Link Layer: Framing, Error Detection (CRC), Flow Control (Sliding Window, Go-Back-N, Selective Repeat), CSMA/CD.
- Network Layer: IPv4/IPv6 addressing, Subnetting, Routing Algorithms (Distance Vector, Link State), RIP, OSPF, BGP, NAT, ARP, ICMP.
- Transport Layer: TCP vs UDP, Flow Control, Congestion Control (Slow Start, Additive Increase Multiplicative Decrease), 3-way handshake.
- Application Layer: DNS, HTTP/HTTPS, FTP, SMTP, DHCP.
- Network Security: Symmetric vs Asymmetric encryption, RSA, Digital Signatures, Firewalls, SSL/TLS.

### 5. Software Engineering & Cloud Technologies
- SDLC models (Agile, Scrum, Waterfall, Spiral).
- Design Patterns, OOP principles, RESTful API architecture.
- Testing methodologies: Black-box, White-box, Unit testing, Integration testing.
- Basics of Cloud Computing (IaaS, PaaS, SaaS, AWS/Azure fundamentals), Virtualization, Docker, and CI/CD pipelines.

### 6. Programming, OOPs & Web Technologies
- Core C / C++ / Java / Python / JavaScript fundamentals.
- Object-Oriented Programming (Encapsulation, Inheritance, Polymorphism, Abstraction).
- HTML5, CSS3, DOM, Web services, JSON.

## 📗 Section B: General Aptitude & General English (25 Questions)

1. **Numerical Ability & Quantitative Aptitude:**
   - Percentage, Profit & Loss, Simple & Compound Interest.
   - Time, Speed & Distance, Time & Work, Pipes & Cisterns.
   - Ratio & Proportion, Averages, Mixtures & Alligations, Permutations & Combinations.
   - Data Interpretation (Bar charts, Pie charts, Tables).
2. **Logical Reasoning & Mental Ability:**
   - Syllogisms, Blood Relations, Direction Sense, Coding-Decoding.
   - Number & Alphabet Series, Seating Arrangements, Analogies, Statement & Assumptions.
3. **General English:**
   - Reading Comprehension, Vocabulary (Synonyms & Antonyms), Idioms & Phrases.
   - Sentence Correction, Error Spotting, Fill in the Blanks, Active/Passive Voice.
