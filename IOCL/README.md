## 🎯 Selection Process & Weightage

The selection process consists of a 3-tier comprehensive evaluation:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Computer Based Test (CBT)                                │
│    • 100 Multiple Choice Questions (Section A + Section B)  │
│    • Objective, Computer-based across major Indian cities   │
└──────────────────────────────┬──────────────────────────────┘
                               │ (Shortlisted in Merit Order)
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. Group Discussion (GD) & Group Task (GT)                  │
│    • Communication, team dynamics & problem solving         │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. Personal Interview (PI)                                  │
│    • Technical depth, behavioral fit, domain knowledge      │
└─────────────────────────────────────────────────────────────┘
```

### Qualifying Cutoff in CBT (Mandatory Gate):
- **General / EWS / OBC-NCL:** Minimum **40% marks in Section A**, minimum **40% marks in Section B**, and **minimum 45% marks Overall (Section A + Section B)**.
- **SC / ST:** Minimum **35% marks in each section** and **40% marks Overall**.
- **PwBD:** Minimum **25% marks in each section** and **30% marks Overall**.
