## ⚡ Which Course to Use for What (Decision Matrix)

| Need | Best Source | Why |
|------|------------|-----|
| **PYQs (most important)** | **IOCL Paper-2** | 3,202 PYQs with 68h video solutions — 2.6x CIL's count |
| **Notes (fast revision)** | **IOCL Paper-2** (557) + **CIL** (1,397) | CIL has 2.5x more notes — use for subjects where IOCL notes are thin |
| **Practice Questions** | **CIL** (5,180) > IOCL (2,430) | CIL has 2.1x more PQs |
| **Concept Videos** | **CIL** (2,940) > IOCL (1,802) | CIL is superset — use only for gap-fill at 2x |
| **Mock Tests (Tech)** | **IOCL Paper-2 Test Series** | 23 tests, exam-pattern specific |
| **Mock Tests (Apt)** | **IOCL Paper-1 Test Series** | 15 tests |
| **Aptitude content** | **IOCL Paper-1** or **CIL** (identical) | Same instructor, same content |

### 🎯 STRATEGY: Notes → PYQs → Wrong-answer video solutions → Mock tests
**Videos are the LAST resort** (2x speed, only for concepts you cannot understand from notes alone).
