# SPMCIL Assistant Manager (IT) -- Syllabus & Exam Blueprint

**Recruitment:** SPMCIL Advt No. `02/2026`  
**Post:** Assistant Manager (IT) -- Level E-1  
**Structure:** 120 Questions / 150 Marks / 120 Minutes  

---

## 📘 Section I: Professional Knowledge (IT / CS) -- 60 Qs / 90 Marks (60% Weightage)

### 1. Programming, Data Structures & Algorithms
- Data Types, Control Structures, Functions, Recursion in C / C++ / Java / Python.
- Arrays, Linked Lists, Stacks, Queues, Binary Trees, Binary Search Trees, Heaps, Graphs.
- Sorting algorithms, Searching algorithms, Time & Space Complexity analysis.
- Object-Oriented Programming (OOP) principles: Inheritance, Polymorphism, Abstraction, Encapsulation.

### 2. Database Management Systems (DBMS)
- Database Architecture, ER Modeling, Relational Data Model.
- SQL queries, subqueries, joins, views, triggers, and stored procedures.
- Normalization (1NF, 2NF, 3NF, BCNF) and Functional Dependency theory.
- Transaction Management: ACID properties, Concurrency Control (2PL, Locks, Timestamps), Recovery.

### 3. Operating Systems & System Architecture
- Process lifecycle, CPU Scheduling, Inter-Process Communication, Threads.
- Synchronization primitives, Semaphores, Mutex, Deadlocks.
- Memory Management: Paging, Segmentation, Virtual Memory, Page replacement algorithms.
- File System architecture, Disk scheduling.

### 4. Computer Networks & Information Security
- OSI and TCP/IP 5-layer model.
- Routing protocols (Distance Vector, Link State, OSPF, BGP).
- Transport Layer protocols: TCP 3-way handshake, Flow control, Congestion control, UDP.
- Application Protocols: HTTP, HTTPS, DNS, SMTP, FTP, DHCP.
- Cyber Security Fundamentals: Symmetric/Asymmetric Cryptography, Hash functions (SHA, MD5), Firewalls, IDS/IPS, OWASP Top 10 vulnerabilities.

### 5. Software Engineering & Web Technologies
- Agile, Waterfall, Scrum methodologies, SDLC.
- RESTful Web APIs, JSON, XML, Microservices concepts.
- Software Testing: White-box, Black-box, Unit Testing, Integration Testing, Regression Testing.

---

## 📗 Section II: Non-Technical Aptitude -- 60 Qs / 60 Marks

1. **General Awareness (15 Qs / 15 Marks):**
   - Current Affairs (National & International), Banking/Financial awareness, Indian Economy, General Science, Static GK.
2. **English Language (15 Qs / 15 Marks):**
   - Reading comprehension, error spotting, fill in the blanks, vocabulary (synonyms, antonyms, idioms), sentence rearrangement.
3. **Logical Reasoning (15 Qs / 15 Marks):**
   - Syllogisms, blood relations, directions, seating arrangement, coding-decoding, series, analogies, critical reasoning.
4. **Quantitative Aptitude (15 Qs / 15 Marks):**
   - Simplification, Number Series, Arithmetic (Percentages, Profit & Loss, Ratio, Time & Work, Time-Speed-Distance), Data Interpretation.
