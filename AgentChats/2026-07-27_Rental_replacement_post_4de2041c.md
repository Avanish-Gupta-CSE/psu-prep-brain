## 📚 IFFCO GET CBT 1 - Technical CS Question Bank Summary

### 🗄️ Database Management Systems (DBMS)

1. **Question:** Changing one employee department requires updates in many records. Which anomaly is present?
   - **Options:** Phantom Read | **Update Anomaly** | Lost Update | Dirty Read
   - **Answer:** **Update Anomaly**
   - **Concept:** Data redundancy in unnormalized tables forces a single logical update to be repeated across multiple tuples, risking data inconsistency if any tuple is missed.

2. **Question:** Which SQL clause filters grouped results after aggregation?
   - **Options:** ORDER BY | **HAVING** | WHERE | DISTINCT
   - **Answer:** **HAVING**
   - **Concept:** `HAVING` filters aggregated groups (e.g., `HAVING COUNT(*) > 5`), whereas `WHERE` filters individual rows prior to grouping.

3. **Question:** A database allows blank middle names but must prevent duplicate university email addresses. Which constraint fits?
   - **Options:** CHECK | **UNIQUE** | NOT NULL | DEFAULT
   - **Answer:** **UNIQUE**
   - **Concept:** `UNIQUE` permits `NULL` (or blank) entries while enforcing uniqueness across all non-null values.

4. **Question:** A transaction updates inventory but fails before sales entry. Recovery restores the earlier state. Which ACID property applies?
   - **Options:** Durability | Consistency | Isolation | **Atomicity**
   - **Answer:** **Atomicity**
   - **Concept:** Atomicity guarantees an "all-or-nothing" execution. If any operation within a transaction fails, all previous changes are rolled back.

5. **Question:** A transaction updates two databases; if one fails, both must roll back. Which protocol fits?
   - **Options:** **Two-Phase Commit (2PC)** | Raft Consensus | Lamport Clock | Gossip Protocol
   - **Answer:** **Two-Phase Commit (2PC)**
   - **Concept:** 2PC is a distributed atomic commitment protocol that uses a *Prepare Phase* and a *Commit/Rollback Phase* to guarantee atomic updates across multiple databases.

### 💻 Operating Systems (OS)

6. **Question:** Free memory is scattered into small non-contiguous blocks despite enough total memory. What is this?
   - **Options:** Thrashing | Deadlock | **External Fragmentation** | Internal Fragmentation
   - **Answer:** **External Fragmentation**
   - **Concept:** Total free RAM is sufficient for an allocation request, but memory is fragmented into non-contiguous holes, preventing contiguous allocation.

7. **Question:** RAM is insufficient, yet applications continue by moving inactive pages to storage. Which mechanism enables this?
   - **Options:** Memory Fragmentation | **Virtual Memory** | Direct Memory Access | Register Allocation
   - **Answer:** **Virtual Memory**
   - **Concept:** Virtual memory extends physical RAM by using secondary storage (swap/paging file) to swap inactive memory pages out to disk.

8. **Question:** Variable-size allocations fail due to scattered free memory despite enough total space. What helps?
   - **Options:** Memory Mapping | Demand Paging | **Memory Compaction** | Copy-on-Write
   - **Answer:** **Memory Compaction**
   - **Concept:** Compaction (defragmentation) relocates allocated memory blocks in physical RAM to combine scattered free memory into one large contiguous block.

### 🌐 Computer Networks & Security

9. **Question:** Login requires password plus approval on a registered mobile device. Which mechanism is used?
   - **Options:** **Multi-Factor Authentication** | CAPTCHA Verification | Password Hashing | Single Sign-On
   - **Answer:** **Multi-Factor Authentication**
   - **Concept:** Multi-Factor Authentication (MFA) requires two distinct factors: *Knowledge* (password) + *Possession* (registered mobile device/authenticator app).

10. **Question:** A site works by IP address but not by domain name. Which service should be checked first?
    - **Options:** FTP | DHCP | SMTP | **DNS**
    - **Answer:** **DNS**
    - **Concept:** DNS translates domain names into IP addresses. If IP connectivity succeeds but the domain name fails, DNS resolution is broken.

11. **Question:** An administrator must block unauthorized inbound connections while allowing approved traffic. Which control fits best?
    - **Options:** Repeater | **Firewall** | Layer-2 Switch | Network Hub
    - **Answer:** **Firewall**
    - **Concept:** A firewall inspects inbound and outbound network traffic against security rules to block unauthorized connections.

12. **Question:** A workstation automatically receives IP address, subnet mask, gateway and DNS server. Which service assigns these?
    - **Options:** **DHCP** | NAT | ARP | DNS
    - **Answer:** **DHCP**
    - **Concept:** Dynamic Host Configuration Protocol (DHCP) automatically assigns network configuration parameters (IP, subnet mask, gateway, DNS) to host devices.

### 🌲 Data Structures & Algorithms (DSA)

13. **Question:** A BST becomes nearly sorted and search time approaches O(n). Which change best restores efficient search?
    - **Options:** **Use a self-balancing tree such as AVL** | Increase application RAM | Store duplicate keys in lists | Convert the tree into a queue
    - **Answer:** **Use a self-balancing tree such as AVL**
    - **Concept:** Sorted input degenerates a basic BST into a skewed linear list with $O(n)$ search time. Self-balancing BSTs (AVL / Red-Black) maintain height $O(\log n)$ via rotations.

14. **Question:** A dynamic array doubles capacity when full. What is the amortized insertion complexity?
    - **Options:** O(log n) | **O(1)** | O(n) | O(n log n)
    - **Answer:** **O(1)**
    - **Concept:** Although doubling capacity takes $O(n)$ time occasionally, spreading the cost of $n$ insertions over $2n$ operations yields an amortized $O(1)$ cost per append.

15. **Question:** A weighted road graph has non-negative edge weights. Which algorithm gives single-source shortest paths?
    - **Options:** Depth-First Search | Breadth-First Search | **Dijkstra's Algorithm** | Prim's Algorithm
    - **Answer:** **Dijkstra's Algorithm**
    - **Concept:** Dijkstra's algorithm computes single-source shortest paths on graphs with non-negative edge weights in $O((V + E) \log V)$ time using a min-priority queue.

16. **Question:** A problem has overlapping subproblems and needs an optimal solution. Which technique fits best?
    - **Options:** **Dynamic Programming** | Greedy Algorithm | Divide and Conquer | Backtracking
    - **Answer:** **Dynamic Programming**
    - **Concept:** Dynamic Programming (DP) solves optimization problems having **Optimal Substructure** and **Overlapping Subproblems** by caching subproblem results.

### ⚙️ Compiler Design, Computer Architecture & Software Engineering

17. **Question:** A loop recomputes an expression whose operands do not change. Which optimization removes this repetition?
    - **Options:** Loop Unrolling | Register Spilling | Dead Code Elimination | **Common Subexpression Elimination**
    - **Answer:** **Common Subexpression Elimination**
    - **Concept:** Common Subexpression Elimination (CSE) identifies redundant evaluations of identical expressions and replaces them with a single temporary variable.

18. **Question:** A compiler must target multiple processors with minimal front-end changes. Which design supports this?
    - **Options:** Independent syntax analyzers | Separate lexical analyzers | Architecture-specific symbol tables | **Retargetable compiler using common IR**
    - **Answer:** **Retargetable compiler using common IR**
    - **Concept:** A retargetable compiler decouples language parsing (Front-End) from machine code generation (Back-End) using an Intermediate Representation (IR).

19. **Question:** A processor executes independent later instructions before earlier ones finish while preserving correctness. Technique?
    - **Options:** Instruction Fusion | Loop Unrolling | Static Scheduling | **Out-of-Order Execution**
    - **Answer:** **Out-of-Order Execution**
    - **Concept:** Out-of-Order (OoO) execution (dynamic scheduling) allows instructions to execute as soon as operands are ready, committing results in-order to ensure correctness.

20. **Question:** Design changes are evaluated for maintainability, scalability, reliability, security and performance. Which activity is this?
    - **Options:** **Architectural Design Review** | Database Backup | Code Formatting | Unit Testing
    - **Answer:** **Architectural Design Review**
    - **Concept:** Architectural Design Reviews evaluate software designs against key quality attributes / non-functional requirements (security, performance, scalability, reliability, maintainability).
