| Parameter | Details |
| :--- | :--- |
| **Exam Mode** | All-India Online Computer Based Selection Test (CBT) + Interview at Bengaluru |
| **Duration** | **2.5 Hours (150 Minutes)** |
| **Total Questions** | **160 MCQs** |
