The selection process is governed strictly by ICRB centralized recruitment rules:

```
┌─────────────────────────────────────────────────────────────┐
│ 1. Written Examination (Computer-Based Test)                │
│    • Part 'A': 80 Discipline-Specific MCQs (CS Core)        │
│      - Time: 90 Minutes | +1 Mark, -1/3 Negative Marking    │
│    • Part 'B': 15 Aptitude / Mental Ability MCQs (20 Marks) │

```
